Everything the iPhone does — your way 🪄

20+ personal-automation triggers mapped to no-root Android equivalents, with a familiar When → Do editor and a deep action set.

⏰

20+ triggers

Time & sun, alarm, sleep, arrive / leave, commute, Android Auto, email, message, Wi-Fi, Bluetooth, NFC, app open/close, airplane, Do Not Disturb, battery, charger, sound — and a Wear OS workout.

🎬

Rich actions

Notify, speak, open app / URL, webhook, Home Assistant, volume / ringer / DND, flashlight, brightness, send SMS, send location, capture photo, record audio, lock, screenshot, alarm, timer.

🔀

Real logic

If / Otherwise branches and Choose from Menu prompts, so one automation can make decisions and ask you what to do.

🛡️

No root needed

Only public Android mechanisms — foreground services, a notification listener, a window-only accessibility service, geofences, and optional Shizuku for a few system toggles.

🔒

Private by design

Automations and any tokens you enter live in the app's private storage — never in a file you didn't export, never sent anywhere you didn't set up.

🌍

7 languages & themes

English, Hebrew (right-to-left), Russian, German, French, Spanish, Italian — plus Light, Dark and true-black AMOLED themes.

The editor ✍️

A familiar When → Do flow

Pick a trigger, add actions, and tune each one. Run after a confirmation or immediately, reorder steps, and hit Run Now to test — just like Shortcuts.

  • Colour-coded triggers and actions, grouped like iOS
  • Per-permission “needs setup” prompts, only when used
  • Export / import your automations as a JSON file
Yours to control 🎛️

Private, themeable, multilingual

A built-in permissions checklist shows exactly what each feature needs and lets you grant it in a tap. No account, no sign-in, nothing phoning home.

  • One-tap permission checklist
  • Light / Dark / AMOLED, seven languages
  • Free and open source under the MIT License
